# LazyVerilog v2.1.1 Release Notes

A formatter reliability release.

## Formatter

- **Many layout fixes** found by stress testing: comments inside lists, headers and expressions, macros, alignment, indentation of continued lines, assertions and coverage, `ifdef` regions, and less common constructs such as `randsequence`, UDP tables, and `config` blocks.
- **Port alignment is now opt-in**, with adaptive columns that stay modest.
- **`whitespace_sensitive` macros keep their arguments exactly as written**, including line breaks and comments.
- **New `statement_terminator_like` macro role** for macros that stand in for a `;`.
- **`wrap_end_else_clauses = false`** now joins `end else` on one line.
- `[format.macros]` roles also apply to macros defined over several lines.
- A trailing `// verilog_format: off` stays on its line as a normal comment.

## Other

- Every command-line binary prints a startup banner, and `lazyverilog-lint` accepts `--nowarn`.
- Documentation now lives at https://lazyverilog.github.io.
