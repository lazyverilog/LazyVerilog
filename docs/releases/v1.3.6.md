# LazyVerilog v1.3.6 Release Notes

Two correctness fixes.

## Fixes

- Fix rename/references treating a module signal and a same-named struct field in an `include`d header as one symbol, so renaming the signal no longer renames the field (fixes #30).
- Fix instance inlay hints counting header `#(...)` parameters as ports, inflating the `N/M ports` coverage count (fixes #29).
