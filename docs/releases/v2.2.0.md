# LazyVerilog v2.2.0 Release Notes

Works without a config file, understands UVM-style code much better, fixes lint warnings for you, and runs on RHEL 8.

## New

- **Lint autofix.** Width, sign and type conversion warnings, a missing `default` in a `case`, and a missing `automatic` now come with a fix. Apply it from the editor's quick-fix menu, or from the command line:
  - `lazyverilog-lint --fix` applies the fixes that cannot change behavior.
  - `--fix-unsafe` also applies the fixes that might, such as a cast inside a parameterized module.
  - `--fix-interactive` asks before each fix, like `git add -p`.

  See [Linter CLI](https://lazyverilog.github.io/linter/cli).
- **No `lazyverilog.toml` needed.** A folder without one is indexed automatically as an implicit project. Set `implicitProject` to `"off"` to turn this off. See [Configuration](https://lazyverilog.github.io/configuration).
- **Document highlight** marks every use of the symbol under the cursor.
- **Smart selection** expands the selection step by step through the code's structure.
- **RHEL 8 support.** The Linux `-static` binaries now need only glibc 2.28.

## Completion

- Suggests inherited class members, members reached through a base class's type parameter (such as `req.` in a UVM driver), and macros from the whole project.

## Navigation and rename

- **Class code:** go to definition, references and rename now handle fields and methods in UVM-style code, including out-of-block bodies and other files.
- **Rename a method** to rename its whole override chain. Rename refuses if the chain goes outside the project, for example into UVM.
- **Same-named classes:** go to definition picks the one the file's imports can see.
- **Macros:** references, rename and go to definition land on the right `define when a macro is redefined, and work on a macro used inside another macro's arguments, such as `` `OUTER(`INNER) ``.
- **Unnamed generate blocks:** references and go to definition now find declarations inside them, including ones a macro declares.
- **Hierarchical paths** such as `top.u_core.sig` resolve correctly on lines with non-ASCII characters.
- **`line directives:** positions stay on the file's real lines. Before, go to definition, hover and references could fail after a `` `line ``.

## Open headers

- A header opened on its own now sees the macros its includer defines, so it no longer shows false "unknown macro" errors.

## Formatter

- Many more layout fixes. Syntax errors no longer spread past their own lines, and merge conflict markers stay intact.
- Format Document now always formats. `enable_format_on_save` only controls saving, and no editor-side setting is needed.

## Speed

- Faster inlay hints while typing, faster completion and references, and faster formatting of long lines.

## Other

- `lazyverilog.toml` mistakes such as unknown keys now produce a warning.
- `[lint.instance]` and `[lint.module]` now honor `enable` and `severity`.

## Upgrading

- The index cache is rebuilt once on the first start.
- Building from source now needs CMake 3.28.
