# LazyVerilog v2.2.1 Release Notes

Bug fixes for non-ASCII text in includes and diagnostics, and comment toggling in VS Code.

## Fixes

- **Diagnostics no longer disappear because of a non-ASCII character.** An unfinished
  `` `include "name `` (no closing quote) that ended in a non-ASCII character such as an emoji
  or Korean text produced an error message the editor could not read, and the editor dropped
  every diagnostic for that file. The include name is now kept whole.
- **Windows: one bad include name no longer stops a file from being analyzed.** An include
  or `` `line `` file name that Windows cannot convert to a path, for example a Latin-1 byte, made the
  whole parse fail. It is now reported as a file that could not be opened, and `` `line ``
  keeps its line numbers.
- Lint messages and quick-fix titles that quote identifiers or source text are now always
  valid UTF-8, even when the source file is not.

## VS Code

- **Toggle Line Comment and Toggle Block Comment work** in `.sv`, `.svh`, `.v` and `.vh` files.
  Brackets, quotes and block keywords such as `begin`/`end` now auto-close and match.

## Upgrading

- The index cache is rebuilt once on the first start.
