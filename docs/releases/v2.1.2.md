# LazyVerilog v2.1.2 Release Notes

A packaging fix for macOS.

## macOS

- **`lazyverilog-lsp` starts again on macOS.** The v2.1.1 macOS binaries crashed on the first request
  from the editor, because the release build stripped symbols the server needs at run time. They are
  now stripped with `strip -x`.
- Every release now checks that the shipped server answers an `initialize` request before it is
  uploaded.

Nothing else changed since v2.1.1.
